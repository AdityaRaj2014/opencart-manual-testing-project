# OpenCart Manual Testing - Test Scenarios

## User Registration

| Scenario ID | Test Scenario |
|---|---|
| TS-REG-01 | Verify that a new user can register successfully. |
| TS-REG-02 | Verify that the system validates mandatory registration fields. |
| TS-REG-03 | Verify that the system validates the email address during registration. |
| TS-REG-04 | Verify that an appropriate validation message is displayed when invalid registration information is entered. |
