Test Scope

In Scope

The following customer-facing functionalities will be tested:
- Home Page
- Product Categories
- Product Search
- Product Details
- User Registration
- User Login/Logout
- Shopping Cart
- Wishlist
- Checkout
- Currency Selection
- Navigation and UI


Out of Scope
The following areas will not be tested:
- Admin Panel
- Performance Testing
- Security Testing
- API Testing
- Database Testing
- Automation Testing


Test Strategy
The OpenCart application will be tested using manual testing techniques.
The following testing approaches will be used:
- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
- Regression Testing
- Retesting of reported defects
Testing will be performed from the customer/user perspective.


Test Environment
Testing will be performed on the OpenCart Store Front using:
- Application: OpenCart E-commerce Store
- Environment: Web Browser
- Operating System: Windows
- Browser: Microsoft Edge
- Testing Type: Manual Testing
- Network: Internet connection

  
Test Schedule
Testing activities will be performed in the following phases:
1. Requirement Analysis
2. Test Planning
3. Test Scenario and Test Case Design
4. Test Data Preparation
5. Test Execution
6. Defect Reporting
7. Retesting and Regression Testing
8. Test Closure


Test Deliverables
The following testing documents and results will be created during the project:
- Test Plan
- Test Scenarios
- Test Cases
- Test Data
- Defect Reports
- Test Execution Results
- Test Summary Report
